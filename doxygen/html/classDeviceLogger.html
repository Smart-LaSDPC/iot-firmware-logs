Descrição detalhada

Recebe os logs da ESP-IDF por um hook e os imprime em uma task dedicada, para que só ela use a serial.

O hook da ESP-IDF é global: só uma instância fica ativa, e ela precisa existir até o reset do dispositivo.

◆ LogMessageFromTagHandle

using DeviceLogger::LogMessageFromTagHandle = std::function<bool(std::string, LogMessage)>

Função chamada para cada mensagem de uma tag, no lugar da impressão na serial.

Roda na task de logs: enquanto ela não retorna, nenhum log é impresso. Por isso não deve bloquear, nem gerar logs com a própria tag, o que a chamaria de novo a cada mensagem.

Parâmetros
tagTag da mensagem.
messageMensagem recebida, já formatada.
Retorna
true se a mensagem foi tratada; false gera um erro na serial, e a mensagem não é impressa.

◆ attatchHandleFunctionToTag()

bool DeviceLogger::attatchHandleFunctionToTag ( std::string  tag,
LogMessageFromTagHandle  handleFunction 
)

Associa uma função às mensagens de uma tag.

Cada tag tem uma função: uma nova associação substitui a anterior. A tag vem do texto da mensagem, então vale para o formato do firmware e para o padrão das bibliotecas pré-compiladas, mas não para mensagens truncadas antes dela.

Parâmetros
tagTag a ser tratada, com até 31 caracteres.
handleFunctionFunção chamada para cada mensagem da tag.
Retorna
true se a função foi associada; false se as associações não foram permitidas no construtor, se a função é vazia ou se begin() já foi chamado, pois a task lê as associações sem sincronização.

Formata a mensagem e a coloca na fila, sem bloquear.

Recebe as mensagens de esp_log_write, em paralelo, de qualquer task. Por isso deve ser reentrante e não pode gerar logs. Roda na pilha de quem gerou o log. Com a fila cheia, a mensagem é descartada e contada; mensagens maiores que LogMessageMaxLenght são truncadas, mantendo a quebra de linha.

Parâmetros
formatFormato recebido da ESP-IDF, já com o prefixo da linha.
argArgumentos do formato, válidos apenas durante a chamada.
Retorna
Quantidade de caracteres formatados, ou valor negativo em caso de erro.

void DeviceLogger::setTagLevel ( const std::string &  tag,
int  level

static

Define em tempo de execução o nível de log de uma tag.

Só alcança logs mantidos na compilação: um nível acima de LOG_LOCAL_LEVEL não tem efeito. A tag "*" vale para todas as tags e descarta os níveis definidos antes, por isso deve vir primeiro.

Parâmetros
tagTag a ser configurada, ou "*" para todas.
levelNível máximo de log da tag, como esp_log_level_t ou como número: 0 nenhum, 1 Error, 2 Warn, 3 Info, 4 Debug e 5 Verbose.

Task que retira as mensagens da fila e chama a função associada à tag, se as associações foram permitidas no construtor. As demais mensagens são escritas na serial.

Quando os descartes atingem droppedLogsToWarn, escreve o aviso direto na serial, pois a fila pode estar cheia.
